# Algoritmos Voraces (Greedy)

## Descripción

Este proyecto implementa dos problemas de optimización utilizando la estrategia de algoritmos voraces (Greedy).

Los problemas desarrollados son:

1. **Mochila fraccional:** selecciona objetos según su relación valor/peso para obtener el mayor valor posible sin superar la capacidad de la mochila.
2. **Cobertura de antenas:** determina las posiciones donde se deben colocar antenas para cubrir todas las casas utilizando la menor cantidad posible.

## Lenguaje utilizado

- C++

## Requisitos

- Tener instalado un compilador de C++, como MinGW o GCC.
- Contar con un editor de código, como Visual Studio Code o Code::Blocks.

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo fuente `.cpp`.
4. Compilar el programa utilizando un compilador de C++.
5. Ejecutar el programa.

### Compilar desde la terminal

Si el archivo se llama `main.cpp` y tienes instalado GCC, utiliza:

```bash
g++ main.cpp -o algoritmos_voraces
```

Después, ejecuta el programa:

**Windows:**

```bash
algoritmos_voraces.exe
```

**Linux:**

```bash
./algoritmos_voraces
```

## Uso del programa

Al ejecutar el programa aparecerá un menú con tres opciones:

1. Mochila fraccional.
2. Cobertura de antenas.
3. Salir.

El usuario selecciona el problema que desea ejecutar e ingresa los datos solicitados.
